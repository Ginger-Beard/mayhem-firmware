# Signature Detect pattern scan table (1 Mb/s GFSK emitters with a fixed sync word).
# One entry per line, FREQMAN style: comma separated key=value fields, any order.
#   name=    shown in lists and logs, up to 23 characters, no comma (required)
#   class=   short tag, up to 4 characters, e.g. TOY (default PAT)
#   ch=      channel centres in MHz, '/' separated, up to 8, e.g. 2429/2449 (required)
#   sync=    sync word in hex as sent on air, first bit = MSB of the first digit (required)
#   bits=    sync length in bits, 8..64 (default: 4 x the hex digits; the last bits are used)
#   err=     bit errors allowed, 0..3 (at most ceil(bits/16)-1 is used: 40 bits -> 2)
#   rate=    1M only (default)
#   inv=     1 if bit 1 is the lower frequency (default 0)
#   dwell=   milliseconds per channel visit, 20..250 (default 60)
#   payload= bits after the sync to return with each hit, 0..64 (default 0, debug only)
# Up to 16 entries, lines up to 160 characters; bad lines are skipped and the first
# one is shown on the app's Debug screen. '#' starts a comment line.
#
