# /GPS/SATFREQ.TXT - satellite downlinks for the GPS app's Follow (receive only).
# Checked 2026-11-13 against AMSAT status (status.amsat.org, reports of Nov 8-13),
# the AMSAT FM / linear frequency summaries (pages dated 2026-10-31), ARISS station
# status (2026-11-04), SatNOGS DB, sigidwiki and WMO OSCAR. Sources per entry and
# what is uncertain: /GPS/README.TXT ("Downlinks"). Satellites change: re-check
# before relying on an entry.
#
# One downlink per line, fields separated by blanks:
#   NORAD  NAME  DOWNLINK  MODE  BW_KHZ  NOTE
# NORAD   catalogue number, matched with TLE.TXT (or "-" to match by NAME, the
#         start of the TLE's name line)
# NAME    one word, for you (and for "-" matching)
# DOWNLINK MHz with a point (437.800) or Hz (437800000), the nominal frequency;
#         the app adds the Doppler shift itself
# MODE    NFM, AM, WFM, USB, LSB, CW (a CW beacon: heard as a 700 Hz tone in USB),
#         DATA (digital: followed and metered, not decoded)
# BW_KHZ  the signal's width (picks the filter), or "-"
# NOTE    the rest of the line (24 characters are shown)
# Lines starting with # are comments. Up to 24 downlinks; a satellite can have
# several (Follow lets you switch). VHF entries (below 300 MHz) need a VHF
# antenna: a 300 MHz-6 GHz panel will not hear them.
#
